# Adhil Navas — Portfolio

A responsive portfolio website built from Adhil Navas's CV.

## Designs

- `index.html` — warm editorial style, with AI/ML and web project filters plus a saved light/dark theme toggle.
- `alt-design.html` — high contrast digital studio style, with project filters.

## Run locally

Open either HTML file in a browser. No build step or package installation is needed. Google Fonts load when online and fall back to system fonts when offline.

## Before sharing

Confirm the contact details and project descriptions. Add project links or screenshots if you want them included. The CV phone number is not displayed.
